# Packaging changes (2026-10-15)

All edits apply only to this independent candidate. Original working trees and raw result records are unchanged. `experiments/manifests/source_files.json` maps copied files to original source checksums; the local audit area stores preparation scripts and the exact copy manifest.

1. Selected core root scripts, utilities and tests from FreeGrasp-derived code. Included the related ThinkGrasp-derived simulation runner, adapters and 16 scene specifications. Kept names where necessary for compatibility.
2. Excluded real-robot/ZED/Piper control, ad-hoc scissors/debug and GUI scripts, author manuscript, images, generated artwork, logs, account metadata, Git history, cached bytecode, binaries, third-party datasets and weights.
3. Kept FGC-GraspNet and graspnet-baseline source snapshots outside this candidate pending redistribution review. GroundingDINO, SAM and graspnetAPI repositories are external installation dependencies.
4. Replaced personal absolute paths with relative paths/environment configuration. Local services bind to loopback by default. Simulation W&B logging defaults to disabled; no tracking account/entity is retained.
5. Delayed LangSAM and Molmo weight initialization until inference. Removed duplicate eager LangSAM initialization from the geometry path. The shared adapter now uses CUDA if available; this can differ from the historical geometry script's default CPU adapter and is not claimed numerically equivalent.
6. Replaced the hard-coded geometry demo with an explicit-target CLI requiring input, target coordinates/class, camera calibration and checkpoint. It does not advertise full language-policy execution or real-robot control.
7. Added `evaluate.py` with explicit stages, data/output paths, splits and subsets. It supplies the module globals expected by the existing Molmo batch implementation; the old combined entry point called that function without initializing those globals. Localization verifies both expected output files before skipping a scene.
8. Reworked static evaluator bookkeeping: persist every processed sample including final failures; retain missing-input/error cases in the denominator; reject mixed-subset and duplicate resume records; recompute accuracy from the complete saved record set; verify mask shapes and GT label presence. Original inference prompts, IoU threshold and ID offset convention are retained. New outputs are not interchangeable with historical runs that skipped missing inputs or failed to persist trailing errors.
9. Added statistics tools that report population and sample SD separately, keep incomplete split collections unaggregated, reject duplicate records, and treat simulation's 1000 no-success sentinel as missing. No original success flag or paper number was changed.
10. Changed target-ID and simulation HTTP image transport to base64 so the root Qwen service can decode it without shared relative paths. No target-selection or scoring rule changed.
11. Preserved `evaluate_target_ids.py` with its original metric logic for provenance, despite its historical `ssr` field name. Documentation explicitly distinguishes ID matching from segmentation success. Added metadata-only dataset membership verification and count export.

The state-memory algorithm and simulation feedback integration were not completed or redesigned as part of packaging. Missing paper mechanisms remain explicitly documented. No model inference, robot motion, simulator episode, API-backed reasoning request, or external publication was performed during this task.
