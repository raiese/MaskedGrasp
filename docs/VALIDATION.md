# Validation performed and limits

Date: 2026-10-15. Checks ran against the independent candidate and read-only original data. No packages were installed or upgraded in the original environments. Model weights were not loaded, no model API call or robot motion was executed, and no simulation episode was run.

## Passed

- Six unit tests: memory scene guidance, failure-driven region guidance, population/sample SD and incomplete split handling, duplicate/invalid result rejection, persistence of a final missing-data failure and resumed denominators, and base64 image transport through a mocked HTTP call.
- Dataset membership verification: all 18 archived split files contain exactly 50 expected samples; 900/900 records match the local Parquet metadata, without extra/duplicate keys.
- Count export and recomputation from the 18 archived split files, the separate incomplete 23-record output, and the 900 target-ID records. Statistics remain separated by collection and metric.
- Historical simulation case-file parsing, with zero-success sentinels excluded from success-conditioned averages. Method identities and pooled episode metrics remain unresolved.
- CLI help for `evaluate.py`, `scripts/infer_grasp.py`, `evaluate_target_ids.py`, and `qwen_service.py` in the appropriate environments. Help success does not verify inference.
- Perception environment imports: torch, torchvision, NumPy, pandas, PyArrow and Open3D.
- Simulation environment imports: torch, PyBullet, Ray, W&B and Open3D.
- Candidate Python syntax parsing and release-content scan. Generated bytecode from a statistics import was removed after the first scan; the final scan reports no findings.
- Original-preservation check: 1,435 selected original source/text/record files have unchanged SHA-256, and the original FreeGrasp Git status is unchanged. This is scoped verification, not a full rehash of multi-gigabyte weights/assets.

Raw check exit codes are in `experiments/summaries/validation_checks.json`; source-preservation evidence and dataset coverage are adjacent. Detailed terminal logs stay in the private local audit directory.

## Observed incompatibility

Importing `Qwen2_5_VLForConditionalGeneration` fails in the existing perception environment, which has Transformers 4.43.3. Qwen service help succeeds in the separate Qwen environment (Transformers 5.5.0). This is recorded as a failed compatibility check, not hidden as a passing full pipeline.

`requirements/observed_versions.json` records package versions from the three existing environments. It is an inventory, not a successful clean-install lock. The proposed perception profile avoids the observed NumPy 2.x/legacy dependency mixture, but that proposed profile has not been installed or validated here. The Qwen recipe targets a separate Transformers 4.x profile; only help/import was checked in the existing 5.5.0 environment, not the proposed profile.

## Not verified

- Clean installation of any proposed dependency profile or compatible native CUDA compilation.
- Molmo/Qwen/GroundingDINO/SAM inference, their quantitative equivalence to original runs, or model snapshot revisions.
- FGC/GraspNet model source installation and operator builds in a fresh environment. These external implementation trees are intentionally excluded from the candidate for license/provenance review.
- Single-frame grasp geometry with real model weights or camera calibration.
- End-to-end PyBullet execution, asset resolution, current target-hit accuracy, the memory-feedback loop, topology pruning, and ablation conditions.
- Reproduction of manuscript Tables II–IV or all of Table I, per-record segmentation flags from original masks, and baseline identity/fairness.
- Real robot execution, lifting/video evidence, any external deployment, GitHub upload, or final license grant.

Two A100 40-GB GPUs were visible and already in use at inspection time. Availability is not a hardware validation result. Offline bookkeeping checks were used; no claim about throughput, VRAM sufficiency or physical success follows from them.
